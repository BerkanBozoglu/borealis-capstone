# BOREALIS systems dashboard

The team's live map of every subsystem, shared number and handoff.

- seed/register.csv: the starting list of 47 shared numbers (owner, confidence, what depends on them).
- docs/: the project files the site's content is taken from.
- CLAUDE_CODE_PROMPT.md: the build instructions for Claude Code.

The site is built automatically from this repo. Rules for editing are added here when the site is built.
